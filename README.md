# civpulse-claude

Claude Code marketplace for [Civic Pulse](https://www.civpulse.org). It contains the `civpulse` plugin, which bundles the Civic Pulse MCP server and civic skills.

## Install

```
/plugin marketplace add CivicPulse/civpulse-claude
/plugin install civpulse@civpulse-claude
```

Then run `/mcp`, select **civpulse**, and sign in. See [plugins/civpulse/README.md](plugins/civpulse/README.md) for details.

## Layout

- `.claude-plugin/marketplace.json`: marketplace catalog
- `plugins/civpulse/`: plugin source
